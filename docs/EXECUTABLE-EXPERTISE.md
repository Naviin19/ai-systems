# Executable expertise

Expert work is usually tacit, fragmented and re-formed every time it is used. This is what happens when it
is treated instead as something that can be represented, constrained, compiled, executed and improved.

---

## Where judgment goes

```
Traditional expert work              Engineered system
──────────────────────────           ────────────────────────────────
domain knowledge                     domain knowledge
        ↓                                    ↓
frameworks                           structured representations
        ↓                                    ↓
heuristics                           contracts and constraints
        ↓                                    ↓
judgment            ────────────┐            ↓
        ↓                       │    agent execution
human interpretation            │            ↓
        ↓                       └──→  verification  ←── judgment, spent once
execution                                    ↓
                                     feedback
                                             ↓
                                     institutional memory
```

Read quickly, the right-hand column looks like it deletes the expert. It does not. Judgment moves from every
step to the gates, and from an opinion re-formed each time to a rule formed once.

The expert is still required where a rule cannot reach: approving what becomes permanent, ending a hardening
loop, deciding at the two human gates, promoting an observation into a rule. **Judgment is not automated
away. It is crystallised, then re-spent where crystallisation fails.**

## A category code is not a brand code

A headline can be factually correct, fully grounded in the source, and worthless. The test a strategist
applies without thinking: swap a competitor's name into the sentence. If it still holds, it is a category
code — true of everyone, owned by no one.

That is now a gate. It runs on every document the system produces, and requires the headline to rest on at
least one of the brand's own scored distinctive assets. The schema had already accepted the sentence; the
gate rejects it and asks again.

A judgment that lived in one person's head, applied only when someone senior read the draft, now executes
every time.

## Category theory as five rejections

Buyers recall brands through category entry points. Distinctiveness precedes differentiation. A claim a
brand cannot substantiate costs more than silence.

Compiled, that becomes five rejections a generated entry must survive: resolution framed as a deficit; an
audience invented rather than grounded in upstream evidence; a competitor ranking the evidence does not
support; a self-declaration nothing substantiates; confidence claimed beyond what the inputs carry.
Enforcement stays narrow — one surgical repair of the offending item, then a deterministic demote or clamp,
capped per document. It never escalates to a stronger model and never drops the section.

## Two frameworks that ship as types

A strategy framework in a document is advice. Agents do not read advice; they read schemas.

The narrative archetypes a brand can occupy ship as an enum. The impact equation that scores the value of a
piece of work ships as a typed object. Both are among the most-imported schemas in the registry, so a
violation is a parse failure rather than a disagreement.

The cost is real: an enum fixes a vocabulary early. An idea that does not fit has nowhere to go but a new
contract version, and the evolution rule is append-only — the enum grows and never shrinks.

## A gate that exists because the model described the method

Asked to write a brand's pillars, a model produced pillars describing *the methodology it had been given* —
distinctiveness before differentiation, category entry points — rather than the brand in front of it.
Structurally valid. Confidently written. Useless.

The gate that catches it encodes what a strategist notices in a second and a schema cannot see at all. The
ladder runs detect → re-ask at the same tier → escalate to a stronger model → **omit honestly**.

## What did not compile

Three refusals, more instructive than the successes.

**Deficit language could not be caught by a lexicon.** Any word list strong enough to catch the real
specimen flagged **19% of legitimate cases**, because pain is a legitimate subject and describing it is not
the same as framing the reader as deficient. The gate refuses to lexicon-gate the entry point at all, and
whitelists the mandated honest idiom first — gating that phrase would train the model *away* from honesty.

**The headline rule has a fence.** It does not fire on headlines that never lean on category claims, and
not at all when a brand has no scorable distinctive assets. A rule that cannot say when it does not apply
is not a rule; it is a preference.

**The last rung is omission.** Every ladder ends in leaving the section out. That is the boundary of
compilation, stated in code: when the encoded judgment cannot produce something worth having, the correct
output is nothing.
